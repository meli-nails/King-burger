Acá llegan las compras de la página. Abrí cada pedido y seguí el botón verde: el sistema te indica qué hacer después.

Cómo se atiende un pedido

1. Confirmar pedido → 2. Enviar a cocina → 3. Marcar como listo → 4. Elegir repartidor. El repartidor inicia la entrega desde su propio panel.

Preparar una salida con varios pedidos

Marcá 2 o más pedidos listos, elegí un repartidor y creá un recorrido. El orden se organiza desde el panel de reparto.

Todavía no seleccionaste pedidos.

Ingresá tu número local, sin 0 ni 15. El sistema agrega automáticamente +54 9 para WhatsApp.
